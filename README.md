#  Tic Tac Toe

A simple and interactive **Tic Tac Toe game** built using HTML, CSS, and JavaScript. This project was created for practice to improve my front-end development skills and understand JavaScript game logic.

##  Features

- Two-player gameplay (X and O)
- Detects the winner automatically
- Identifies a draw when all cells are filled
- Restart the game and play again
- Simple and user-friendly interface
- Responsive game interactions

##  Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactivity

##  Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd tic-tac-toe
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code.

##  How to Play

1. Player X starts the game.
2. Players take turns selecting empty cells.
3. The first player to get three marks in a horizontal, vertical, or diagonal line wins.
4. If all cells are filled and nobody wins, the game ends in a draw.
5. Restart the game to play again.
